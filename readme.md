# AiFans - AI Dating Application

## Описание проекта

AiFans - это инновационное приложение для знакомств, использующее искусственный интеллект для создания виртуальных персонажей и интерактивного общения. Приложение построено на базе Flet (Python) и интегрирует различные AI-сервисы для генерации контента.

## Основные возможности

### 🤖 Генерация AI-персонажей
- Автоматическое создание уникальных персонажей с детализированными характеристиками
- Генерация внешности, характера, увлечений и предпочтений
- Реалистичные профили с историей и особенностями личности

### 💬 Интерактивный чат
- Умные диалоги с AI-персонажами
- Контекстное запоминание разговоров
- Поддержка мультимодального контента (текст, изображения)

### 🎨 Генерация изображений
- Создание портретов персонажей
- Технология face swap для консистентности лиц
- Различные стили и форматы изображений

### 📱 Tinder-подобный интерфейс
- Свайпы влево/вправо для лайков/дизлайков
- Просмотр полных профилей
- Система уведомлений о совпадениях

## Системные требования

- Python 3.8+
- Windows/Linux/macOS
- Интернет-соединение для работы с AI API
- Минимум 4GB RAM

## Установка

### 1. Клонирование репозитория
```bash
git clone <repository-url>
cd AiFans
```

### 2. Создание виртуального окружения
```bash
python -m venv venv
venv\Scripts\activate
```

### 3. Установка зависимостей
```bash
pip install flet
pip install openai
pip install together
pip install pillow
pip install pydantic
pip install google-generativeai
pip install requests
```

### 4. Настройка API ключей
Создайте файл `.env` в корневой директории проекта:
```env
OPENAI_API_KEY=your_openai_api_key
TOGETHER_API_KEY=your_together_api_key
GOOGLE_API_KEY=your_google_genai_key
SEGMIND_API_KEY=your_segmind_api_key
```

### 5. Создание необходимых папок
```bash
mkdir assets\chapters
mkdir storage
mkdir output
```

## Запуск приложения

### Основное приложение
```bash
python main.py
```

### Tinder-интерфейс
```bash
python tinder.py
```

### Генерация персонажей
```bash

```

## Конфигурация

### config.json
Основной конфигурационный файл содержит:
- Примеры анкет пользователей
- Настройки предпочтений
- Шаблоны для генерации контента

### Настройка AI-сервисов

#### OpenAI API GEMINI
- Используется для генерации диалогов

#### Together AI
- Альтернативный провайдер для чатов
- Поддержка различных open-source моделей

#### Google Gemini
- Генерация персонажей и контента
- Мультимодальные возможности

#### Segmind API
- Face swap технология
- Обработка изображений

## Ключевые модули

### Генерация персонажей (gemini_exp.py)
- Создание детализированных профилей
- Pydantic модели для структурирования данных
- Генерация внешности и характера

### Чат-система (chat.py)
- Обработка мультимодального контента
- Интеграция с различными AI API
- Сжатие и обработка изображений

### UI/UX (main.py, tinder.py)
- Flet-based интерфейс
- Адаптивный дизайн
- Система навигации

## Разработка

### Добавление новых AI провайдеров
1. Создайте новый класс в соответствующем модуле
2. Реализуйте стандартные методы API
3. Добавьте конфигурацию в config.json

### Кастомизация UI
1. Модифицируйте файлы в assets/
2. Обновите стили в main.py/tinder.py
3. Добавьте новые компоненты по необходимости
