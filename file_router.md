Какой файл за что отвечает:
- fainder_test.py - Рабочее приложение, к сожалению ннаписанно все в одном файле поэтому очень трудно ореинтироваться
- chapter.py - файл, содержит класс Chapter который служит для удобного использования данных персонажа в коде (chapter.name и тд)
- chat.py - файл с чатом (устаревший)
- funccall.py - Чат в консоли, сделан для того что бы тестировать функции, там разрабатываются функции и методы которые должны будут быть введены в интерфейс чата
- image_flux_generation.py - файл, содержит класс FLUX который служит для генерации изображений с помощью flux имеет flux 1.1 pro flux kontext max/pro
- gemini_exp.py - Мозг генератора, задает настройки нейростям и используется для генерации всего, от личности до картинки
- infinity_girl_generate.py - Бесконечный генератор персонажей, использует цикл и нейросеть для генерации
- main.py - содержит только стартовую страницу
- photo_editor.py (устарело) - содержит код для придания картинки более реалистичной графкик (искажений) не требуется для новой модели генераций
- tinder.py (утсрело) - не полная версия приложения (без чатов) но можно брать оттуда функции
